## 🚀 Currently building: **Pub Jukebox** 🎵

> A real-time, room-based music queue. The host creates a room, guests join with a display name, everyone adds songs, and the queue stays in sync live.

```text
   ┌────────────┐   WebSocket (STOMP)   ┌──────────────────┐      ┌─────────┐
   │ React App  │ ◄───────────────────► │ Spring Boot API  │ ◄──► │  Redis  │
   │ host/guest │        REST           │ rooms · queue    │      │ state   │
   └────────────┘ ────────────────────► └──────────────────┘      └─────────┘
                                                 │
                                                 ▼
                                        YouTube playback
```

| 🧩 Layer | ⚙️ Tech | 🎯 Why |
|---|---|---|
| Frontend | React | Live queue UI, host/guest views |
| Backend | Java, Spring Boot | Room logic, REST + WebSocket |
| State | Redis | Fast, ephemeral room & queue state |
| Hosting | OCI Always Free (Ampere VM) + Nginx | Real-world deployment on a free tier |
